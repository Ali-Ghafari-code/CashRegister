# کش‌رجیستر — سامانه صندوق فروش و مدیریت خرده‌فروشی سازمانی

پلتفرم یکپارچه POS و مدیریت خرده‌فروشی به زبان فارسی و طراحی راست‌به‌چپ (RTL). این مخزن، **بخش رابط کاربری (Next.js)** پروژه است و شامل صفحه صندوق فروش لمسی، پنل مدیریت اجرایی و صفحات ماژول‌های اصلی سازمانی می‌شود.

## اجرای سریع

```bash
npm install
npm run dev
# http://localhost:3000
```

## ساختار

- `src/app/page.tsx` — صفحه اصلی (Landing)
- `src/app/pos/` — صفحه صندوق فروش (POS)
- `src/app/dashboard/` — پنل مدیریت (Back Office)
  - `dashboard/` (داشبورد اجرایی)
  - `sales/` — فروش‌ها
  - `products/` — کاتالوگ کالا
  - `inventory/` — موجودی انبار
  - `transfers/` — انتقال بین شعب
  - `purchases/` — خرید و فاکتور تأمین
  - `suppliers/` — تأمین‌کنندگان
  - `customers/` — مشتریان (CRM)
  - `loyalty/` — باشگاه وفاداری
  - `promotions/` — پروموشن و تخفیف
  - `payments/` — پرداخت‌ها و درگاه‌ها
  - `cash/` — مدیریت صندوق و شیفت
  - `accounting/` — حسابداری و مالیات
  - `employees/` — کارکنان
  - `branches/` — شعب و صندوق‌ها
  - `reports/` — گزارش‌ها
  - `audit/` — لاگ رخداد و ژورنال الکترونیکی
  - `integrations/` — یکپارچه‌سازی‌ها
  - `notifications/` — اعلان‌ها
  - `security/` — امنیت و دسترسی (RBAC)
  - `settings/` — تنظیمات

## استک فنی

- **Next.js 15 (App Router)** + **React 19**
- **Tailwind CSS 3** با تم اختصاصی و پشتیبانی RTL
- **TypeScript**
- **Vazirmatn** (فونت فارسی) از CDN
- **jalaali-js** برای تقویم شمسی
- **lucide-react** برای آیکون‌ها
- SVG سبک اختصاصی برای نمودارها (بدون وابستگی به کتابخانه‌های سنگین)

## ویژگی‌های رابط کاربری

- طراحی راست‌به‌چپ (RTL) کامل با تایپوگرافی فارسی و اعداد فارسی.
- صفحه POS با میانبرهای صفحه‌کلید (F1/F2/F4/F6)، جست‌وجوی کالا، انتخاب دسته، سبد خرید، تخفیف خطی، سبدهای نگه‌داشته و مودال پرداخت ترکیبی.
- داشبورد اجرایی با KPI، نمودار ۱۴ روزه، ترکیب پرداخت، فروش ساعتی و وضعیت شعب.
- صفحات ماژولی برای همه بخش‌های اصلی سازمانی (کالا، انبار، خرید، مشتری، وفاداری، پروموشن، پرداخت، صندوق، حسابداری، شعب، امنیت، اعلان‌ها و ...).

## توسعه بعدی

این ریپو فعلاً فقط لایه UI را دارد. لایه‌های بعدی که باید اضافه شوند:

- Domain / Application services و مدل‌های داده
- API با Next Route Handlers یا NestJS جدا
- پایگاه داده (PostgreSQL + Prisma)
- سرویس همگام‌سازی آفلاین (IndexedDB + Outbox)
- آداپتورهای پرداخت، سخت‌افزار و صورتحساب الکترونیکی
- تست‌های واحد، یکپارچه و E2E
